WIBlog structure

Inside WIPlugin/WIBlog/ we should use this pattern:

WIPlugin/WIBlog/
│
├── plugin.json
├── update.json
├── index.php
│
├── Install/
│   ├── install.php
│   ├── uninstall.php
│   ├── upgrade.php
│   └── WI_Blog.sql
│
├── blog/
│   ├── WIBlog.php
│   ├── WIBlog_Options.php
│   ├── WIBlog_Admin.php
│   ├── WIBlog_Render.php
│   ├── WIBlog_SEO.php
│   ├── WIBlog_Permissions.php
│   │
│   └── WIInc/
│       ├── blog.php
│       ├── posts.php
│       ├── categories.php
│       ├── comments.php
│       ├── settings.php
│       ├── design.php
│       ├── seo.php
│       └── analytics.php
│
└── assets/
    ├── css/
    ├── js/
    └── images/
What each file should do
WIPlugin/WIBlog/blog/WIBlog.php

Main plugin bootstrap/controller.
It should:

load helper classes

expose plugin metadata

route admin/frontend requests

stay light

WIPlugin/WIBlog/blog/WIBlog_Options.php

Logic only.
It should:

read/write settings from wi_blog_settings

return defaults

validate options

not own the full HTML screen

WIPlugin/WIBlog/blog/WIInc/blog.php

This becomes the admin shell page, same idea as your main admin zone:

tab navigation

include smaller pages

clean layout

WIPlugin/WIBlog/blog/WIInc/settings.php

Options UI only.

WIPlugin/WIBlog/blog/WIInc/design.php

Design/color/layout UI only.

WIPlugin/WIBlog/blog/WIInc/seo.php

SEO options UI only.
