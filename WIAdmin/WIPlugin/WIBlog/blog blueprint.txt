1️⃣ First observation — Good foundation

Your structure already follows a very good philosophy:

file-based plugin

database only for data

That is exactly how long-lasting CMS plugins should be built.

So we are improving, not rewriting.

2️⃣ plugin.json review

You already have metadata support which is excellent.

However for marketplace compatibility we should expand it slightly.

Recommended plugin.json
{

3️⃣ update.json

This is a very good idea and something most CMS forget.

However it should look like this:

{
  "plugin": "WIBlog",
  "version": "1.0.0",
  "download_url": "https://wicms.com/plugins/WIBlog.zip",
  "release_date": "2026-01-01",
  "changelog": [
    "Initial release",
    "SEO improvements",
    "Admin UI improvements"
  ],
  "requires": {
    "wicms": ">=1.0.0",
    "php": ">=8.2"
  }
}

Later this allows automatic plugin updates.

4️⃣ SQL review (WI_Blog.sql)

The database structure is already good.

However I recommend adding a few fields to future-proof it.

Add fields for SEO
meta_title VARCHAR(255),
meta_description TEXT,
meta_keywords TEXT
Add fields for publishing workflow
status ENUM('draft','published','scheduled','private') DEFAULT 'draft',
scheduled_date DATETIME NULL
Add fields for analytics
views INT DEFAULT 0,
likes INT DEFAULT 0
Add fields for authorship
author_id INT
Add fields for revisions
revision INT DEFAULT 1
5️⃣ WIBlog.php review (architecture)

Your core file is doing too many responsibilities.

Currently it likely mixes:

rendering

database access

settings

admin logic

For long-term maintainability we should split it.

Recommended split
blog/

WIBlog.php
WIBlog_Render.php
WIBlog_Admin.php
WIBlog_Options.php
WIBlog_Permissions.php
WIBlog_SEO.php
Responsibilities

WIBlog.php

bootstrap plugin
load classes
register hooks

WIBlog_Render

frontend blog output
post lists
single post
categories

WIBlog_Admin

admin panel
editor UI
post management

WIBlog_Options

plugin settings
design options
layout settings

WIBlog_Permissions

roles
editor rights
post ownership

WIBlog_SEO

meta tags
schema
sitemap
