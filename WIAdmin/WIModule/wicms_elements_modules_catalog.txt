SUGGESTED STORE PRICING MODEL
-----------------------------
Elements - free tier
- heading, paragraph, image, button, link, separator, rows, columns, textbox, notice, list, logo
Price: Free

Elements - low-cost tier
- accordion, tabs, progress_bar, call_to_action, content_box, feature, subscribe, image_hover
Price: GBP 4.99 to 9.99 each

Elements - premium tier
- slider, carousel, post_carousel, google_map, search_engine, price_box, image_mosaic, video embed, gallery, advanced forms
Price: GBP 9.99 to 24.99 each

Modules - free tier
- header, footer, menu, panel, top_head, sidebar, left_sidebar, welcome_box, heading, notice, columns
Price: Free

Modules - standard tier
- team_showcase, slider, blog, listings, flipcard, profile_tabs, forum, product, loop
Price: GBP 14.99 to 39.99 each

Modules - premium / vertical tier
- shop, cart, checkout, hospitality booking, compliance dashboard, menu management, reservation suite, healthcare bundles
Price: GBP 39.99 to 149.99 each

Page template packs
- about us, contact, landing page, services, pricing, faq, blog home, product page, profile page, reservation page
Price: Free to GBP 29.99 per pack

Recommended bundle logic
- Keep the basic builder toolbox free
- Charge for advanced interaction, ecommerce and industry-specific packs
- Offer subscription bundles for store updates and new releases
